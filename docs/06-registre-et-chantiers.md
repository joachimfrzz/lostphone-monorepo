# Registre des questions ouvertes et chantiers

## Questions ouvertes (routées en D27)

- **Q-FINS** — Doctrine de signalement des fins : le joueur doit-il savoir qu'il existe d'autres fins ? Rejouabilité assumée ou fin vécue comme unique ? *(origine : D09 (sous-point différé) ; destination : Fin de bloc A ou avec le lot de propositions.)*
- **Q-VULU** — Mutations non destructrices : quand le joueur lit une conversation, laisse-t-il des traces « vu / lu » visibles des personnages ? Lourd de sens en posture inconnu reconnu. *(origine : D12 (révélée par la doctrine des bords) ; destination : Grammaire de l'enquête (P08) ou arbitrage dédié.)*
- **Q-SERRURES** — Dosage des serrures/codes : combien de preuves par le geste de type « code » avant que le jeu ressemble à un escape game ? *(origine : D14 ; destination : Grammaire de l'enquête (P08).)*
- **Q-ANDROID** — Délai iOS → Android : combien de temps l'audience Android (majeure sur le genre) attend-elle ? *(origine : D11 (signalement) ; destination : Plan de release (hors phase fondations).)*
- **Q-SAISIE** — Surface de saisie libre hors checkpoints : une vraie messagerie a toujours un clavier — comment offrir la saisie libre aux moments d'expression seulement, sans fissure d'immersion ni attente d'un personnage-chatbot ? *(origine : B1.1 (posée le 2026-07-20, découle de « l'IA interprète, jamais auteur ») ; destination : Grammaire de l'enquête (P08) / conception UX, après B1.)*
- **Q-POIDS** — Poids de téléchargement de l'app : une interprétation locale embarquée peut peser lourd — friction d'acquisition pour une app gratuite. Budget de poids à définir ; interagit avec la portée des histoires téléchargeables. *(origine : B1 (2026-07-20, option locale) ; destination : Phase technique (contrainte à garder en tête au design).)*
- **Q-PRIX** — Principe de prix du catalogue : prix par format type cinéma (reco, ancrage 3-5 € constaté par P14) ou prix libre par histoire. Différé après deux passes sans réponse. *(origine : B2.4 (2026-07-20) ; destination : Plan de release.)*
