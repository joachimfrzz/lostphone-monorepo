# D01 — Méthode : fondations d'abord

- **Date** : 2026-07-20
- **Statut** : EN VIGUEUR

## Décision

Aucun développement, aucun choix d'architecture, aucun code tant que les fondations ne sont pas posées et validées par l'utilisateur.

## Justification

Préférer découvrir les problèmes majeurs en conception plutôt qu'après des mois de développement.
