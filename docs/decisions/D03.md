# D03 — Contrat de collaboration : challenge actif et traçabilité

- **Date** : 2026-07-20
- **Statut** : EN VIGUEUR

## Décision

L'assistant challenge activement et propose sur tous les plans. Distinction obligatoire décisions utilisateur (canon) vs apports assistant (étiquettes [RECO]/[IDÉE]/[RISQUE]/[TENSION]/[QUESTION]). Seul l'utilisateur promeut en décision.

## Justification

L'objectif n'est pas de défendre les idées initiales mais de construire le meilleur jeu possible, sans que les idées de l'assistant se glissent silencieusement dans la vision.
