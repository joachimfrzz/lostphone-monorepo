# D08 — Arbitrage A1 : posture du joueur dans la fiction

- **Date** : 2026-07-20
- **Statut** : ACTÉ

## Décision

Trois postures admises au niveau socle (témoin invisible, inconnu reconnu, usurpateur). Posture = attribut déclaré par histoire. Première histoire : inconnu reconnu. Usurpateur réservé aux histoires ultérieures. Règle attachée : chaque histoire doit rendre crédible le fait que le joueur garde le téléphone (jamais de 'pourquoi ne pas simplement le rendre ?').

## Justification

Les trois postures reposent sur les mêmes capacités socle (messagerie, contacts réactifs) — garder les portes ouvertes ne coûte presque rien. L'inconnu reconnu offre le porteur diégétique naturel des checkpoints, le confort moral et une écriture maîtrisable pour la première histoire.
