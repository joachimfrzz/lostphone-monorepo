# D10 — Arbitrage A3 : modèle temporel du téléphone vivant

- **Date** : 2026-07-20
- **Statut** : ACTÉ

## Décision

Doctrine hybride à moteur événementiel : (1) le moteur de progression est événementiel — rien de ce qui fait avancer une histoire n'est conditionné à l'horloge réelle ; (2) l'horloge réelle sert à l'habillage de crédibilité (horodatages, délais plausibles), jamais de verrou ; (3) battements scénarisés disponibles comme outil de mise en scène, déclenchés par conditions de scène ; (4) la pression temporelle est dramatique, jamais chronométrique (corollaire D09) ; (5) modèle déclaré par histoire, défaut socle = événementiel ; temps réel strict possible en choix éditorial exceptionnel assumé.

## Justification

Seule option tenant la double contrainte « jamais bloqué / jamais dirigé » ; l'attente réelle est l'irritant n°1 du genre ; les sessions mobiles sont courtes et irrégulières. Rend P02 (guidage par le monde vivant) structurellement cohérente.

## Exigence attachee

Le socle brouille la causalité perçue (délais variables, événements décorrélés) pour éviter l'effet « monde qui t'attend ».
