# D11 — Arbitrage A4 : cible — plateformes, écrans, tons, âge, durée

- **Date** : 2026-07-20
- **Statut** : ACTÉ

## Décision

(1) Smartphones : cible = iOS ET Android ; aucune décision de conception ne doit dépendre d'une exclusivité de plateforme ; séquencement acté dans son principe : iOS lancé EN PREMIER (nuance utilisateur), Android ensuite — délai exact au futur plan de release. (2) Tablette : compatibilité minimale (rendu téléphone centré), aucun design dédié ; PC : hors périmètre v1 sans rien décider qui l'interdise structurellement. (3) Tons : spectre large admis avec cœur d'identité réaliste à mystère — histoires ancrées dans le réel avec quelque chose à élucider ; comédie/romance en variations occasionnelles ; surnaturel rare et volontairement exceptionnel. (4) Classification : plafond de conception = pas de contenu classé adulte (18+) ; thèmes durs suggérés/hors-champ plutôt que montrés ; détail en C5 (charte). (5) Durée : gamme de formats nommés, éditoriale (bornes indicatives à affiner : affaire courte 1-2h, enquête 3-5h, grande affaire 6h+) ; le socle reste agnostique à la durée.

## Justification

Une référence du jeu mobile gratuite ne peut ignorer la moitié du marché ; l'illusion EST le format téléphone ; un cœur d'identité protège la marque sans monotonie ; le plafond d'âge conditionne l'écriture et la découvrabilité ; des formats nommés rendent lisible l'unité de valeur (B2) et cohérents avec la tranche verticale (P09).

## Signalement sans relitige

Grosse audience Android sur le genre : un décalage iOS→Android trop long laisserait ce public de côté — à garder pour le plan de release.
