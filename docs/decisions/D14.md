# D14 — Arbitrage A7 : doctrine des checkpoints de compréhension

- **Date** : 2026-07-20
- **Statut** : ACTÉ

## Décision

(1) Porteur diégétique déclaré par histoire ; en témoin invisible, pas d'expression libre sans destinataire crédible → vérification par l'action uniquement. (2) Preuve par le geste co-prioritaire (P15 PROMUE) : l'action informée (taper un code déduit, appeler la bonne personne, transmettre la bonne pièce, prendre la bonne décision) vérifie la compréhension à égalité avec l'expression libre ; l'expression n'a jamais le monopole ; choix scène par scène. (3) Porteur = personnage, jamais oracle : en interne la vérité est nette, en surface le porteur réagit selon son caractère (doute, croyance à tort, panique) ; dans les histoires sans fin d'erreur son scepticisme EST la correction narrative ; dans celles qui usent de D09 il peut suivre la fausse piste du joueur. (4) Anti-énumération : sur les checkpoints à fort enjeu, la validation porte sur le raisonnement (le lien), pas le mot-clé ; le porteur réagit humainement au brute-force ; les gestes sont protégés par des mécanismes réalistes (verrouillage progressif d'un PIN). (5) Jamais de mur : après N tentatives d'expression rejetées, sortie de secours diégétique obligatoire (bascule vers une action, question simplifiée, ou hypothèse portée par le personnage) ; un checkpoint d'expression n'est jamais un point de blocage dur ; chaque checkpoint se conçoit avec sa sortie.

## Justification

Le checkpoint est le mécanisme signature ET le risque n°1 (R1, faux négatifs = pire frustration possible). La co-priorité du geste réduit l'exposition au texte libre, est sans ambiguïté dans toutes les langues, et constitue le seul outil des histoires témoin invisible. Garde-fou de dosage à définir dans la grammaire (P08) : trop de codes et de verrous transformeraient le jeu en escape game.

## Exemples de reference

- Code : la galerie de Léa est verrouillée ; sa mère écrivait « ton code, c'est toujours l'anniversaire de Rocky » ; médaille du chien sur une photo + rappel « anniv Rocky » le 14 mars dans l'agenda → taper 1403 prouve le recoupement sans rien formuler.
- Bonne personne : comprendre que « J. » = Jade (la collègue) et non Julien (le copain) → appeler Jade prouve la compréhension ; appeler Julien = suivre la fausse piste, l'histoire réagit.
- Bonne pièce : Emma demande « envoie-moi ce que t'as trouvé de plus important » → transférer le relevé bancaire louche plutôt que la photo du lac.
- Décision finale : envoyer l'adresse du rendez-vous à la police ou y aller seul — le choix révèle qui le joueur croit coupable.
- Porteur non-oracle : « …j'y ai pensé aussi. Mais il était à Lyon ce week-end-là, non ? » (doute qui corrige sans corriger).
- Anti-énumération : « Pourquoi tu dis ça ? » / « Tu devines ou tu sais ? »
- Sortie de secours : « Attends, on s'embrouille. Concrètement : tu penses qu'elle est partie où ? » ou « Bon, essaie le code de la galerie, on verra bien ».
