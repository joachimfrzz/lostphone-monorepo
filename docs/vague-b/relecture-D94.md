# Relecture D94 des retraits de la vague B — proposition (08/09/2026, 00h30)

Règle D94 (Joachim, 07/09 22h43) : les apps sont une **plateforme pour toutes les histoires**. Un élément retiré
au titre de D92 se rejuge sur « une histoire plausible pourrait-elle s'en servir ? », pas sur « Sarah s'en sert-elle ? ».

Trois verdicts possibles :
- **RÉINTÉGRER** — utile à des histoires variées, coût raisonnable, source visuelle disponible → à faire au prochain lot.
- **BACKLOG GÉNÉRIQUE** — utile mais coûteux ou source manquante → construit quand une histoire le demande (ou quand la source arrive).
- **NON** — décoratif, publicitaire ou sans conséquence possible dans un téléphone hors ligne : reste retiré.
