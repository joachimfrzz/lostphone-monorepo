# Fiche de vérification — Calendrier (campagne D84, session 2)

**Protocole (≤5 min)** : fais le tour ci-dessous sur le VRAI iPhone puis sur Lost Phone.
Pour chaque écart : une paire de photos (vrai / jeu) OU une ligne de frustration (vocal ou texte).
Les 5 axes : pixel · touchers (D82 : A faire-marcher > B message crédible > C retirer) · navigation & gestes · contenu Sarah · animations.

## Tour de l'app
1. Vue MOIS : scroll continu (fév 2025 → déc 2026), le 17 août en rouge (présent du jeu), pastilles d'évènements
2. GRILLE : vérifier que les jours tombent juste (ex. le 1er août 2026 = samedi)
3. Vue ANNÉE : 12 mini-mois, mois courant en rouge ; tap sur un mois → il s'ouvre
4. Vue JOUR : évènements positionnés à la bonne heure avec durée/lieu, auto-scroll ~8h
5. CRÉER un évènement (titre/lieu/date/heure) → il persiste et apparaît dans Mois/Jour
6. RECHERCHE : « banque » → le RDV du 17/08

## Boutons à tester
- Bascules Mois/Année/Jour + retour « Aujourd'hui »
- Tap sur chaque évènement → sa fiche
