# Fiche de vérification — ChatGPT (campagne D84, session 6)

**Protocole (≤5 min)** : fais le tour ci-dessous sur le VRAI iPhone puis sur Lost Phone.
Pour chaque écart : une paire de photos (vrai / jeu) OU une ligne de frustration (vocal ou texte).
Les 5 axes : pixel · touchers (D82 : A faire-marcher > B message crédible > C retirer) · navigation & gestes · contenu Sarah · animations.

## Tour de l'app
1. Accueil Chat/Work « Salut Sarah »
2. Conversation scriptée « cadeau maman » : lisible, crédible
3. MESSAGE LIBRE : une réponse locale unique (D18 : AUCUNE IA d'exécution — c'est voulu, juge la crédibilité du wording)
4. Panneau latéral ; bibliothèque ; projets

## Boutons à tester
- Micro/casque et autres icônes : B crédible ou C, jamais un bouton mort

## Contenu Sarah attendu
Historique de conversations qui raconte Sarah (recherches cadeau, questions du quotidien)

## Pièges connus
- Ne pas juger l'app sur « l'IA répond pas comme la vraie » : réponse locale = décision de fond
