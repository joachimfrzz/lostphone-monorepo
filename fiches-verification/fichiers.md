# Fiche de vérification — Fichiers (campagne D84, session 4)

**Protocole (≤5 min)** : fais le tour ci-dessous sur le VRAI iPhone puis sur Lost Phone.
Pour chaque écart : une paire de photos (vrai / jeu) OU une ligne de frustration (vocal ou texte).
Les 5 axes : pixel · touchers (D82 : A faire-marcher > B message crédible > C retirer) · navigation & gestes · contenu Sarah · animations.

## Tour de l'app
1. Récents : grille avec VRAIES vignettes photo (pellicule), bascule Icônes/Liste, tri
2. Menu contextuel appui long : Coup d'œil, Lire les informations, Renommer, Compresser, Dupliquer, Tags…
3. Fiche Infos complète ; aperçu plein écran (image réelle / page PDF)
4. Recherche à jetons (« Le nom contient “x” ») + état vide
5. Explorer : favoris, emplacements, Suppressions récentes RÉCUPÉRABLES, 10 tags colorés
6. Dossiers : Documents / Kiné / Billets
