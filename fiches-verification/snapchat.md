# Fiche de vérification — Snapchat (campagne D84, session 5)

**Protocole (≤5 min)** : fais le tour ci-dessous sur le VRAI iPhone puis sur Lost Phone.
Pour chaque écart : une paire de photos (vrai / jeu) OU une ligne de frustration (vocal ou texte).
Les 5 axes : pixel · touchers (D82 : A faire-marcher > B message crédible > C retirer) · navigation & gestes · contenu Sarah · animations.

## Tour de l'app
1. Thème : CLAIR pour chat/carte/stories, SOMBRE pour caméra/spotlight
2. Chat : chips My AI/Groupes/Près de moi ; statuts Reçu (carré bleu) / Remis (flèche violette) / « Appuyer pour Chatter » ; badge C+ 47
3. Conversation : noms colorés (MOI rouge / ami bleu) + barre verticale, champ « Envoyer un Chat » réel
4. Snap Map : carte Lyon réelle en CLAIR + épingles amis + pilule % exploré
5. Caméra : viseur diégétique sombre + capture ; Stories (ronds violets + Découvrir) ; Spotlight (plein écran + rail)

## Boutons à tester
